# Следующий этап: бронирование и уведомления

После выбора постоянного хостинга нужно реализовать следующие возможности.

## Администратор

- безопасный отдельный вход для владельца сайта;
- календарь со всеми временными окнами;
- ручная отметка свободных и занятых слотов;
- просмотр, изменение и отмена заявок.

## Автоматическое бронирование

- хранение слотов и заявок в базе данных;
- атомарное бронирование, чтобы один слот нельзя было занять дважды;
- автоматическое скрытие или блокировка занятого времени на публичной странице;
- подтверждение записи для ученика и администратора.

## Telegram-уведомления

- Telegram-бот и согласие ученика на получение сообщений;
- привязка Telegram-пользователя к заявке;
- настраиваемое время напоминания перед занятием;
- журнал доставки и повторная отправка при ошибке.

Эти функции намеренно не имитируются в локальной версии: для надёжной работы им нужны постоянная база данных, серверные задачи и безопасное хранение ключа Telegram-бота.
