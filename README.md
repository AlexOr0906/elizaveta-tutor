# Сайт частного репетитора

Многостраничный сайт-визитка с отдельными разделами:

- главная страница;
- информация о репетиторе;
- форматы и стоимость занятий;
- расписание и форма записи.

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска сайт доступен по локальному адресу, указанному в терминале.

## Проверка сборки

```bash
npm run build
```

Сайт не использует пользовательские аккаунты или встроенную авторизацию.
