# Сайт частного репетитора

Многостраничный сайт частного репетитора с отдельными разделами:

- главная страница;
- информация о репетиторе;
- форматы и стоимость занятий;
- расписание и форма записи.

На Timeweb сайт использует PHP и MySQL:

- показывает реальные свободные даты из базы данных;
- атомарно резервирует окно и не допускает двойной записи;
- сохраняет заявки и отправляет уведомление на почту;
- предоставляет закрытую админ-панель `/admin`;
- позволяет создавать, закрывать и открывать временные окна;
- позволяет подтверждать, отклонять и отменять заявки;
- создаёт ручные и автоматические резервные копии.

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска сайт доступен по локальному адресу, указанному в терминале.

## Проверка сборки

```bash
npm run build
```

## Подготовка версии для Timeweb

```bash
npm run build
node scripts/export-github-pages.mjs
node scripts/export-timeweb.mjs
```

Готовая папка: `timeweb-site`. Секретный `.private/config.php` намеренно не попадает в экспорт и не перезаписывается при обновлении.

Подробная настройка описана в `TIMEWEB_DEPLOYMENT.md`.
