# Развёртывание расписания и админ-панели на Timeweb

## 1. Файлы

Загрузите содержимое архива `elizaveta-booking-admin-v8.zip` в папку `Liza/public_html` с заменой существующих файлов. Архив не содержит рабочий `.private/config.php`, поэтому пароль базы и почты не перезаписываются.

## 2. Настройка администратора

В существующий `Liza/public_html/.private/config.php` добавьте рядом с разделами `database` и `mail`:

```php
'admin' => [
    'username' => 'elizaveta',
    'password_hash' => 'СЮДА_ХЕШ_ПАРОЛЯ',
    'session_name' => 'elizaveta_admin',
],
```

Хеш можно безопасно создать через SSH-консоль Timeweb, запустив `php Liza/public_html/cron/hash-admin-password.php`. Сам пароль в конфигурации и исходном коде хранить нельзя.

После настройки вход доступен по адресу `https://lizochkaorlowa.ru/admin/`.

## 3. Создание таблиц

Таблицы `tutor_slots`, `tutor_bookings` и `tutor_admin_login_attempts` создаются автоматически при первом открытии расписания. Если таблица слотов пустая, система создаёт реальные даты на ближайшие шесть недель по текущему недельному графику.

## 4. Резервные копии

В админ-панели есть кнопка «Скачать резервную копию».

Для автоматической ежедневной копии в разделе Timeweb «Crontab» добавьте запуск PHP-файла:

```text
Liza/public_html/cron/backup.php
```

Скрипт работает только из командной строки, складывает JSON-копии в закрытую папку `.private/backups` и хранит их 30 дней.

## 5. Проверка после загрузки

1. Открыть `/api/schedule.php` — должен вернуться JSON со свободными слотами.
2. Открыть `/booking/` — должны появиться конкретные даты.
3. Отправить тестовую заявку — выбранное окно должно исчезнуть.
4. Войти в `/admin/`, подтвердить заявку и скачать резервную копию.
5. Проверить получение письма.
